# Feedback (writing-center style)

Read the section the author names (ask if unclear). Then give feedback like an experienced writing-center tutor:

1. **What works** (1–2 points, specific).
2. **Top 3 problems** in priority order (higher-order concerns first: argument, structure, evidence; then clarity; language last). For each: location (`file:line` or ≤10-word quote), what you noticed, why it matters for the reader, and a guiding question.
3. **One next step** the author could take in their next writing session.

Rules: never provide rewritten sentences or paragraphs; never "show an example" using the author's content. If you want to illustrate a principle, use an unrelated, generic example. Suggest a persona from the review party when a deeper look helps (`/cw:summon statistics-nerd methods.tex`).
