# Structure check

Read the named file(s) (default: everything in `manuscript/`). Produce:

1. **Reverse outline**: one line per section/paragraph saying what it *does* (e.g. "introduces gap", "reports test of H2"), with line numbers.
2. **Argument map**: main claim → supporting claims → evidence (citation/data) → marked gaps `⚠ no evidence`, `⚠ no link to RQ`.
3. **Red-thread check**: does each section answer the research question(s)? Where does the order break?
4. **3 questions** for the author.

Save the outline as `notes/ai/structure-<date>.md` with the AI-generated header if the author wants to keep it. Never propose replacement text.
